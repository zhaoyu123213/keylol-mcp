# Keylol 日报生成规则

## 触发方式
当用户说"日报"、"生成日报"、"今日总结"等类似指令时，按以下流程执行。

## 流程
1. 确认目标日期（默认今天）
2. 读取 `keylol_output/newthread/{日期}/` 下所有 md 文件
3. 如果该目录为空或不存在，先调用 `scrape_keylol(mode="newthread", date=目标日期, max_pages=3)` 爬取
4. 读取所有帖子内容，按板块分类汇总
5. 生成日报 md 文件，保存到用户指定的输出目录（建议 `output/daily/{日期}.md`）

## 日报格式

```markdown
# Keylol 日报 {YYYY-MM-DD}

> 今日新帖 {N} 篇，涵盖 {板块1}、{板块2}... 等板块

## 🎮 购物心得 / 福利放送
（与 Steam 游戏购买、优惠、免费领取相关的帖子）

| 帖子 | 简评 | 热度 |
|------|------|------|
| [标题](url) | 一句话总结帖子内容+评论区观点 | 🔥/💬N |

## 🌐 热点聚焦 / 华语汉化
（游戏新闻、汉化发布等）

| 帖子 | 简评 |
|------|------|
| [标题](url) | 一句话总结 |

## 💬 谈天说地 / 其他
（灌水、问答、杂谈等）

| 帖子 | 简评 |
|------|------|
| [标题](url) | 一句话总结 |
```

## 分类规则
根据帖子来源板块或内容判断：
- 购物心得(f234)、福利放送(f319)、慈善包(f271) → 🎮 购物/福利
- 热点聚焦(f161)、华语汉化(f257) → 🌐 热点/汉化
- 谈天说地(f148)、综合讨论(f251)、其他 → 💬 杂谈

## 简评规则
- 每个帖子用一句话概括：主楼在说什么 + 评论区的主流观点/补充信息
- 如果评论区有争议或有价值的补充，简要提及
- 不要照搬标题，要提炼信息增量
- 热度标记：评论多(>10)用 🔥，否则用 💬+评论数

## 注意事项
- 日报要精简，一眼能扫完
- 购物/福利类帖子排最前面（用户最关心）
- 如果某个帖子内容太水或无实质信息，可以跳过不写
- 帖子链接用 keylol.com 的完整 URL
